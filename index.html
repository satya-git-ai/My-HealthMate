Built for Performance

Platform & UI

  • Native Android architecture
  • 100% Kotlin codebase
  • Modern UI built exclusively with Jetpack Compose

Plugins & Tooling

  • Kotlin Symbol Processing (KSP) for efficient code generation
  • Roborazzi integrated for accurate visual snapshot testing
  • Foojay toolchain resolver convention for seamless JVM management
  • Resilient Google Services configuration (builds succeed without local JSON)

Build & Resource Optimization

  • High-performance Gradle environment: 4GB JVM heap (-Xmx4g), in-process Kotlin compilation, parallel execution, and configuration caching
  • Maximized machine stability with builds explicitly capped at 4 workers
  • Minimized APK size utilizing non-transitive R classes to reduce compiled resources
