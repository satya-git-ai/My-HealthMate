Under The Hood

Technical Stack & Configuration

Platform & UI

  • 100% Native Android application architecture.
  • Built securely and efficiently using Kotlin.
  • Modern, reactive user interface developed with Jetpack Compose.

Plugins & Tooling

  • Uses Kotlin Symbol Processing (KSP) for faster code generation.
  • Integrates Roborazzi for automated visual snapshot testing.
  • Incorporates Google Services, configured to allow successful builds even if the google-services.json file is temporarily missing.
  • Utilizes the Foojay toolchain resolver convention for JVM management.

Build Optimization

The Gradle environment is strictly optimized for performance and stability to ensure rapid iterations.

  • 4GB JVM heap (-Xmx4g)
  • In-process Kotlin compilation
  • Parallel execution & configuration caching
  • Max workers explicitly capped at 4 to prevent machine overload

Resource Management

The project is configured to keep the final output lean. We enable non-transitive R classes to significantly reduce the overall size of the compiled resources, leading to a smaller, more efficient APK footprint for users.
